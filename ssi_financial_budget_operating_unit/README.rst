==================================
Financial Budget + Operating Unit
==================================

Glue module that adds Operating Unit support to the Financial Budget module.
Extends ``financial_budget.budget`` with ``mixin.single_operating_unit``, so
financial budget documents can be scoped and restricted per operating unit.
